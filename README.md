# LedgerLine

LedgerLine helps you keep track of income and expenses in one place.

## Overview

Use LedgerLine to maintain a clear record of financial activity. Add transactions with a date, description, amount, and category, then review your history to understand where your money is going.

## Core capabilities

- Track income and expenses
- Categorize and describe transactions
- Browse transaction history
- Search and filter records

# LedgerLine

## Project Description
LedgerLine is a money movement and financial integrity application.

It is designed to manage accounts, deposits, withdrawals and transfers while maintaining accurate financial records.

## Main Objectives
- Secure user authentication
- Role-based access control
- Account management
- Deposits and withdrawals
- Money transfers
- Double-entry ledger
- Idempotency protection
- Concurrency safety
- Audit trail

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python FastAPI
- Database: PostgreSQL
- Testing: Pytest
- Version Control: Git and GitHub
